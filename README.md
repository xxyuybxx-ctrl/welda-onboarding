## 빌더 출처 (GLP-1 제안_ver.B · GLP-1 온보딩 · 여성의원 제안 …)

- 자료 올리기 · 제목 고치기 · 관리자(사번) 등록은 **Claude 빌더에서만** 됩니다. GitHub 빌더는 보기 · 고르기 · PPT/PDF 받기 전용.
- Claude 빌더에서 올린 자료는 **자동으로** GitHub 빌더에 반영됩니다: 예약 작업이 매일 07:42–20:42(KST) 매시간 `builder/data/`를 갱신하고, 빌더·교육자료를 고치는 작업 끝에도 항상 동기화합니다. 절차는 `tools/SYNC.md`, 스크립트는 `tools/sync_sources.py`.
- 관리자 사번은 저장하지 않고 변환값(SHA-256)만 Claude 빌더 DB에 둡니다.

## 2026.11.18 의료진용 개편

- 44장 전체를 의료진용 새 테마(흰 배경 · 네이비 제목 · 보라 강조 · 육각형 번호 배지)로 다시 만들었다. PPTX는 글자 · 도형 · 차트를 고칠 수 있는 파일이다.
- 빌더 · 슬라이드 보기 · 스크롤 웹페이지를 같이 갱신했다. 빌더 번호(s01–s44)는 그대로라 저장된 구성은 그대로 열린다.
- 바로잡은 내용: 13p 비만주사 근거 그래프(BMJ 2026 메타분석 수치로 다시 그림), '10월 적용 예정' 문구 삭제, 맞춤법 · 띄어쓰기 · 용어 통일. 자세한 목록은 `src/deck/점검결과_261118.md`.
- s43 · s44(생활습관 기록 앱 · 웰다 Pro 화면)는 서울미즈병원 제안 6 · 7p에서 가져왔다.
