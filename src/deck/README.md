# 의료진용 교육자료 생성기 (2026.11.18)

`files/웰다_교육자료_261118_의료진용.pptx`는 이 폴더의 코드로 만든다. 슬라이드 문구·배치를 고칠 때는 PPTX를 직접 고치기보다 여기를 고친 뒤 다시 만든다.

- `lib.js` 공통 서식(색, 글꼴, 육각형 번호 배지, 카드, 화면 캡처 테두리 · 강조 박스)
- `ch1.js` 표지 · 목차 · 챕터 표지 · 1장 / `ch23.js` 2 · 3장 / `ch45.js` 4 · 5장 · 마무리
- `build.js` 순서대로 44장 생성 (빌더 순서와 같음: s01–s05, s43, s44, s06–s42)
- `assets/` 화면 캡처(빨간 박스 지운 것), BD, 포스터, QR, 아이콘
- `점검결과_261118.md` 기존 B안 점검 내용

만들기: `python3 sizes.py && node build.js` (Node `pptxgenjs`, `react-icons`, `sharp` 필요, 글꼴 Pretendard)
이미지 · PDF: `render.sh welda_clinical.pptx out/s 180` (LibreOffice. 한글과 영문 사이 자동 띄어쓰기를 끄고 변환)

서식 기준
- 흰 배경, 제목 네이비 #1B2559 28pt 굵게, 챕터 라벨 보라 #6B4EF0 12pt, 본문 #252B3B
- 강조 박스는 보라 실선 + 육각형 번호 배지, 빨간 박스 쓰지 않음
- 합니다체, '해 주세요' 띄어 쓰기, 용어: 연속혈당측정기(센서) · 웰다 Pro · 당뇨전단계
